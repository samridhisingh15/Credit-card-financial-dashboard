# 💳 Credit Card Financial Dashboard

## 📌 Project Overview

The **Credit Card Financial Dashboard** is a data analytics and business intelligence project developed using **SQL and Power BI**.

The project analyzes credit card customer and transaction data to understand financial performance, customer behavior, transaction patterns, revenue, and other important business metrics.

The project uses CSV datasets as the source data, SQL for data analysis, and Power BI for interactive dashboard visualization.

---

## 🎯 Project Objective

The main objectives of this project are:

* To analyze credit card transactions
* To understand customer behavior
* To analyze revenue and transaction performance
* To study customer demographics
* To identify spending patterns
* To analyze credit card categories
* To track important financial KPIs
* To generate meaningful business insights
* To support data-driven decision making

---

## 🛠️ Technologies Used

* **Power BI** – Dashboard and data visualization
* **SQL** – Data querying and analysis
* **DAX** – Calculated measures and KPIs
* **CSV** – Source datasets

# 📌 Key Performance Indicators

The dashboard focuses on important KPIs such as:

| **Revenue**            | Total revenue generated                 |
| **Transaction Amount** | Total value of transactions             |

# 🚀 How to Use the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/rishabhnmishra/Credit_Card_Financial_Dashboard.git
```

### Step 2: Use the Dataset

Use the following CSV files:

```text
cc_add.csv
credit_card.csv
cust_add.csv
customer.csv
```

### Step 3: Run SQL Queries

Open:

```text
SQL Query - Financial Dashboard Data.sql
```

Execute the required queries in your SQL environment.

### Step 4: Open Power BI

Open **Microsoft Power BI Desktop**.

### Step 5: Load the Data

Import/connect the required data into Power BI.

### Step 6: Create Relationships

Create relationships between customer and transaction datasets.

### Step 7: Create DAX Measures

Create the required calculations and KPIs using DAX.

### Step 8: Create Dashboard

Create interactive charts, KPI cards, tables and slicers.
